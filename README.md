# DevMate AI

DevMate AI is an AI-powered CLI assistant for developers.

It helps developers:

- Ask technical questions from terminal
- Explain errors
- Save useful fixes
- Search old solutions
- Sync notes with backend
- Generate developer runbooks

## Current Status

Stage 1: Basic Go CLI setup.

## Run Locally

```bash
go run ./cmd/devmate
```
