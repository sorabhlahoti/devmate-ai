# Working Guide

## Run CLI

```bash
go run ./cmd/devmate
Show Help
go run ./cmd/devmate --help
Show Version
go run ./cmd/devmate version
Build Binary
go build -o bin/devmate ./cmd/devmate
```

## Run Built Binary

### Windows:
```bash
./bin/devmate.exe version
```
#### Linux/Mac:
```bash
./bin/devmate version
```
